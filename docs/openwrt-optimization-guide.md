# OpenWrt / OpenClash 网页操作指南

只需要手机或电脑的浏览器，不需要打开终端。以下操作可能让网络短暂中断，别在通话、上课或下载时做。页面名称随固件版本可能不同；找不到对应项目就跳过，不要找一个相似的开关代替。

## 1. 登录并备份

1. 连上家里的 Wi-Fi，在浏览器打开家人给你的路由器管理地址。
2. 登录后看首页「状态 → 概览」的设备型号。若家里两台设备共用一个地址，先确认显示的是要改的那台。型号对不上就停。
3. 前往「系统 → 备份/升级」，在备份区点「生成备份」并下载。文件留在自己电脑上，不发到群里。这个备份不一定包含所有 OpenClash 自定义文件。

## 2. 关闭防火墙流量卸载

1. 打开「网络 → 防火墙」，找到「常规设置」或「路由/NAT 分载」。
2. 先截图记下原设置。找到「软件流量卸载」和「硬件流量卸载」，把已勾选的取消。关闭软件卸载后硬件项如果自动隐藏，不用再找。若界面是下拉菜单，选择「禁用」。
3. **只有家人确认这台是单臂旁路由**，并且界面明确显示「FullCone NAT / 全锥形 NAT」开关时，才把它关闭。不确定就保持原样。
4. 点「保存并应用」，等页面重新连上。刷新后确认改过的选项没有恢复，再试开一个平时能访问的网站。若变更后上不了网，回到同一页按截图还原。

## 3. OpenClash 改成每周日重启

1. 打开「服务 → OpenClash」，在「插件设置」中找「定时重启」。确认设置写的是 **OpenClash 重启**，不是 OpenWrt 的整机重启。
2. 启用定时重启，星期选「周日」，时间选「04:00」。不要改订阅更新设置；原来每天 05:00 更新的就保留。
3. 点「保存并应用」，刷新后确认仍显示「周日、04:00」。不要点「立即重启」来测试定时任务。找不到星期选项就交给家人处理，不要只改小时。

## 4. 不需要自己做的项目

| 项目 | 怎么处理 |
|---|---|
| TUN 协议栈 | 不改。R2S 保留现有 `system`，UTM 保留现有 `gvisor`。 |
| 自定义嗅探 | 交给家人做。不只要勾选开关，还要装最终覆写并检查实际运行配置；只勾开关可能无效。 |
| IPv4 ICMP 重定向、DNS 缓存和 LAN IPv6 | 交给家人。部分固件没有完整的网页选项；不要为了找开关关闭 DHCP、修改网关或禁用整网 IPv6。 |
| 清理文件、整机定时重启 | 不做。 |

家人可参考[维护交接文档](HANDOFF_OPENWRT_OPT_2026-11-24.md)；其中的脚本如用于补做优化，应保留不清文件、不新增整机重启的选项。

## 5. 检查能不能正常用

1. 在 OpenClash「运行状态」确认服务在运行；用实际经过这台路由器的设备，分别打开一个平常直连的网站和一个平常走代理的网站。
2. 同一设备打开 [ipleak.net](https://ipleak.net/)，等 DNS 检测结束，把结果截图私下发给家人核对。只凭 DNS 地址所在国家不能判断是否泄漏。
3. 如果操作后出问题，把你改的是哪一项、之前的截图和现在的页面发给家人。不要恢复出厂设置，也不要随意重启整台路由器。

OpenClash 网页功能可参见[项目官方说明](https://github.com/vernesong/OpenClash)；以实际安装版本显示的选项为准。
